# ADR-002: Two-Stage DLP & Reversible Token Vault

**Status:** Accepted  
**Date:** 2026-11-09  
**Last modified:** 2026-11-09

## Context

The gateway must protect against data exfiltration of PII, secrets, and confidential business information. Entity detection must be both fast (sub-50ms) and comprehensive. Real PII must never leave the gateway boundary, and any tokens/values that do reach the model must be sanitized before client delivery.

The gateway runs on CPU inside the Python process, so detection has to fit a sub-50 ms budget for typical prompts and must not require a GPU. Tokens have to stay stable for the life of a session (so multi-turn conversations remain coherent) but must not outlive the conversation, and detokenisation may only happen for the authenticated client — never before a model call or inside an audit record.

## Decision

1. **Stage 1 — Deterministic Presidio scrubber**: `presidio-analyzer` + `presidio-anonymizer` detect PII categories (PERSON, EMAIL_ADDRESS, PHONE_NUMBER, IBAN, IP_ADDRESS, API_KEY, CREDIT_CARD, etc.). Detected entities are immediately replaced with session-scoped tokens: `{{ENTITY:PERSON_1}}`, `{{ENTITY:EMAIL_1}}`, etc.

2. **Stage 2 — Semantic sensitivity classifier**: An ONNX-runtime distilled sequence classifier (small DeBERTa/MiniLM) runs inside the Python process. It tags prompts as `CONFIDENTIAL` or `PUBLIC`. `CONFIDENTIAL` prompts are routed by OmniRoute to `local-llama`; `PUBLIC` prompts go to `cloud-primary`.

3. **Reversible token vault (Redis)**:
   - Maps `{{ENTITY:TYPE_INDEX}}` → encrypted real value (AES-256-GCM).
   - Stored under session key `vault:{session_id}` with 30-min TTL.
   - Values never written to disk; encrypted at rest.
   - On egress, tokens are detokenized back to original values for the authorized client only.

4. **Canary token injection**: A session-unique `CANARY-<uuid4>` string is embedded into the system prompt. If this string appears in model output or untrusted tool output, the egress filter trips the circuit breaker and blocks the response.

## Consequences

- **Pros**: PII never touches the model; semantic classification catches what regex misses; reversible vault preserves semantic relationships; canary detects indirect prompt injection.
- **Cons**: Presidio CPU cost (mitigated by ONNX fallback); vault TTL requires session cleanup; canary false positives if model legitimately echoes system instructions (handled via override).
